Connect AI agents to TooDue

The TooDue MCP server lets Claude, ChatGPT, Cursor, VS Code, and any other Model Context Protocol client read and manage your to-do list. You sign in through your browser and choose exactly what the agent may do. No API keys to copy.

Server URL

https://app.toodue.com/mcp

Self-hosting? Use https://<your-domain>/mcp. The exact URL is shown in the app under Settings → AI agents.

How connecting works

  1. Add the server URL to your agent as a remote (HTTP) MCP server.
  2. Your agent opens a TooDue page in your browser. Log in if you aren't already.
  3. Review the request and choose permissions: view (always), create & update, and delete.
  4. Click Allow access. The browser hands you back to the agent, which is now connected.

The agent gets a short-lived access token that refreshes automatically. It never sees your password. You can see every connected agent, and disconnect any of them instantly, under Settings → AI agents.

Setup by client

Claude (claude.ai and Claude Desktop)

  1. Open Settings → Connectors and choose Add custom connector.
  2. Name it TooDue and paste https://app.toodue.com/mcp.
  3. Click Connect and approve access in the browser window that opens.

Claude Code

claude mcp add --transport http toodue https://app.toodue.com/mcp

Then run /mcp inside Claude Code, select toodue, and choose Authenticate.

ChatGPT

  1. Open Settings → Apps & Connectors (turn on developer mode under Advanced if needed).
  2. Create a connector with the URL https://app.toodue.com/mcp and authentication set to OAuth.
  3. Approve access when TooDue opens.

Cursor

Add to ~/.cursor/mcp.json (or .cursor/mcp.json in a project), then click Connect next to TooDue in Cursor's MCP settings:

{
  "mcpServers": {
    "toodue": { "url": "https://app.toodue.com/mcp" }
  }
}

VS Code (GitHub Copilot)

Add to .vscode/mcp.json or your user MCP configuration, then start the server and sign in when prompted:

{
  "servers": {
    "toodue": { "type": "http", "url": "https://app.toodue.com/mcp" }
  }
}

OpenAI Codex CLI

Add to ~/.codex/config.toml:

[mcp_servers.toodue]
url = "https://app.toodue.com/mcp"

Then run codex mcp login toodue.

Clients that only support local (stdio) servers

Bridge with mcp-remote. It handles the browser sign-in for you:

{
  "mcpServers": {
    "toodue": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://app.toodue.com/mcp"]
    }
  }
}

Permissions

PermissionScopeAllows
View your projects and tasksreadAlways granted. Projects, tasks, sub-tasks, comments, due dates.
Create and update taskswriteAdd, edit, reschedule, complete, and comment on tasks; create projects.
Delete tasksdeletePermanently remove tasks and their sub-tasks.

Agents only see the tools their permissions allow. To change permissions, connect again from the agent and approve a different set. The new set replaces the old one.

Tools

ToolScopeWhat it does
toodue_agendareadOverdue tasks plus tasks due in the next N days (default 7). Pass today as your local date.
toodue_list_projectsreadAll your projects (including shared ones) with ids and active task counts.
toodue_get_projectreadOne project with its members.
toodue_list_tasksreadIncomplete tasks, optionally for one project; or recently completed tasks in a project.
toodue_search_tasksreadFind incomplete tasks by name or description.
toodue_get_taskreadA task with sub-tasks, comments, and attachments.
toodue_mereadThe account the agent is acting as.
toodue_create_taskwriteCreate a task or sub-task. Goes to your Inbox unless a project is given.
toodue_update_taskwriteRename, reschedule, re-prioritize, move, or set a repeat rule.
toodue_complete_taskwriteComplete or reopen a task. Completing a repeating task schedules the next one.
toodue_add_commentwriteComment on a task.
toodue_create_projectwriteCreate a project, optionally nested.
toodue_delete_taskdeletePermanently delete a task.

Dates are YYYY-MM-DD, times are 24-hour HH:MM, and priority runs from 1 (P1, most urgent) to 4 (P4, default). Changes made by agents appear instantly in every open TooDue app and sync to Google Calendar like any other edit.

Things to ask your agent

  • “What's on my plate today? Anything overdue?”
  • “Turn these meeting notes into tasks in my Work project, due next week.”
  • “Move everything overdue to tomorrow and bump the invoice task to P1.”
  • “Plan my week: spread my unscheduled Home tasks across the next five days.”

Using an API key instead

For scripts, CI, or agents that can't do browser sign-in, create a key in Settings → API keys and send it as a bearer token to the same endpoint. API keys have full access to your account. 

{
  "mcpServers": {
    "toodue": {
      "url": "https://app.toodue.com/mcp",
      "headers": { "Authorization": "Bearer tdue_your_key_here" }
    }
  }
}

Security

  • Only approve a connection you just started yourself. The consent page shows the agent's name and where you'll be sent afterward.
  • Agents act as you, including in projects others have shared with you.
  • Disconnecting an agent in Settings revokes all of its tokens immediately.
  • Access tokens last one hour. Refresh tokens rotate on every use and expire after 90 days of inactivity.

For MCP client developers

TooDue implements the MCP authorization spec over the Streamable HTTP transport (stateless, JSON responses; GET /mcp returns 405).

EndpointPurpose
POST /mcpJSON-RPC endpoint. Protocol versions 2024-11-05 through 2025-11-25.
/.well-known/oauth-protected-resource/mcpProtected resource metadata (RFC 9728), also linked from the WWW-Authenticate header on 401.
/.well-known/oauth-authorization-serverAuthorization server metadata (RFC 8414).
POST /oauth/registerDynamic client registration (RFC 7591). Public clients only.
GET /oauth/authorizeAuthorization code flow. PKCE with S256 is required. URL-based client IDs (client ID metadata documents) are supported.
POST /oauth/tokenauthorization_code and refresh_token grants (form-encoded).
POST /oauth/revokeToken revocation (RFC 7009).

Redirect URIs must be https, http on a loopback address (any port), or a private-use app scheme such as cursor://. OAuth access tokens work only at /mcp; use API keys for the REST API.
